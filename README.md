# Verilog RTL Design and Verification

A collection of digital design and verification projects
developed using Verilog HDL.

## Tools and Technologies
- Verilog HDL
- Ubuntu Linux
- Icarus Verilog
- GTKWave
- Visual Studio Code

## Projects

### 1. AND Gate
A 2-input AND gate with a Verilog testbench.

- Tested all four input combinations.
- Verified using Icarus Verilog.
- Waveform analysis using GTKWave.

[View AND Gate Project](01_AND_GATE/)

### 2. OR Gate
A 2-input OR gate with a Verilog testbench.

- Tested all four input combinations.
- Verified using Icarus Verilog.
- Waveform analysis using GTKWave.

[View OR Gate Project](02_OR_Gate/)

## Learning Goals
- Digital logic design
- Verilog RTL coding
- Testbench development
- Simulation and debugging
- Waveform analysis
